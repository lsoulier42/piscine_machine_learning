# Piscine Machine Learning — Python

Parcours pratique inspiré de la pédagogie 42, suite de [piscine_python](https://github.com/lsoulier42/piscine_python). Projet original, non affilié à l'École 42.

## Objectif
Comprendre et implémenter les algorithmes classiques du machine learning, en découvrant progressivement les outils Python et les mathématiques nécessaires.

## Méthode
- Exercices `ex00`, `ex01`… à réaliser dans l'ordre ; aucun corrigé fourni.
- D'abord implémenter les mécanismes avec Python/NumPy, puis comparer avec scikit-learn lorsque le sujet l'autorise.
- Lire le `SUBJECT.md` de chaque exercice et respecter les dépendances indiquées.
- Tester cas nominaux, limites et erreurs ; documenter les expériences et les métriques.
- Ne jamais entraîner et évaluer sur les mêmes observations ; prévenir la fuite de données.

## Environnement
Python 3.11+ ; environnement virtuel recommandé. Installer progressivement `numpy`, `pandas`, `matplotlib`, `scikit-learn`, `pytest` selon les modules.
